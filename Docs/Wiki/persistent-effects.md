# 持续效果与 OPS 修正

description：按效果参数查本回合持续状态的生效、到期、取消，以及 OPS 的行动者归属、上下限和地区花费历史。首批为越南起义、遏制政策、红色恐怖／清洗。

状态：规则设计与参数绑定；没有 C#、Unity 或可玩的效果处理器。入口：[模块描述](../Descriptors/active-effects.module.json) → [数据描述](../../Data/Descriptors/persistent-effects-batch1.data.json) → [唯一参数文件](../../Data/Cards/deluxe-2015/persistent-effects-batch1.parameters.json)。卡牌印刷 OPS 仍从 cards.json 读取，地区成员仍从 world.json 读取。

## 对象职责与持久化契约

| 对象／计划服务 | 保存内容或职责 |
|---|---|
| EffectDefinition | 只读模板、受影响方策略、持续期限、修正类型、参数引用；不含当前回合状态 |
| ActiveEffectInstance | instanceId、effectId、sourceCardId、sourceResolutionId、controller、affectedSide、activatedTurn、activatedSequence、expiresAt、definitionVersion、dataDigest、status、结束原因与序列 |
| ActiveEffectService | Activate / ExpireAtBoundary / Cancel；生成事务变更计划，不由 UI 直接改状态 |
| OpsContext | contextId、sourceKind、sourceCardId 或 verifiedAsIfCardOps、actor、turn、创建序列、规则摘要、效果快照、mode、spent、按序目标历史 |
| OpsModifierService | Quote；返回原始值、各修正来源、条件奖励、有效预算及合法性，不修改卡牌定义 |

计划路径与符号见模块描述的 `planned_entrypoints`；`entrypoints` 留空。保存数据使用稳定 ID 与值，不保存 Unity 对象、函数指针或 UI 回调。实例载入时验证引用、版本、摘要、期限与唯一性；未知效果或跨版本冲突停止，不删除未知项后继续游戏。状态只允许 Active → Expired 或 Cancelled；重复终结命令返回原记录。

## 激活、到期、取消流程

1. 事件编排确定事件控制者、结算 ID 和当前权威序列。越南受影响方固定苏联；遏制固定美国；中立牌清洗取事件控制者的对手。出牌者、当前行动方、事件控制者和实际 OPS 行动者不可混用。
2. 校验参数与上下文，生成立即影响力变更及 ActiveEffectInstance；越南的两部分在同一结算事务提交。复用影响力事件的 `AddExact` 语义，直接增加不消耗 OPS，也不乘 OPS 修正。
3. 同一 sourceResolutionId、effectId 的重试必须比较完整请求摘要：相同则返回已提交结果，不再加影响力；同 ID 不同请求为冲突。另一结算 ID 同回合对同方再次激活同效果暂为 `RequiresRuling`，既不累加也不覆盖，整项事件不提交。
4. 到期挂在既有回合末链：军事结算 → 扣留计分牌审计 → 回合末胜负 → 中国牌就绪 → 回合末选择 → `ExpireAndReset` → 下一回合或最终计分。`expiresAt` = 激活回合的此边界。早期直接结束游戏时不再执行后续回合步骤；结束快照保留历史。
5. Cancel 只接受经验证的规则处理器提供的原因、取消来源与目标实例 ID。三张首批牌没有在本批授权任何游戏内取消事件；取消用合成案例检验状态契约，不据此声称某张牌能取消它们。未来永久效果须单独定义期限，本批模板不能猜测支持。

到期幂等；已结束实例保留审计记录但不再参与报价。若下一回合仍载入上一回合 Active 实例，应报状态一致性错误，不能把它继续当作加成。卡牌弃置/移除与实例终结是两个独立流程。

## OPS 报价与行动地区

基值只来自真实卡牌的 `printed_ops`，或已验证事件提供的“视同 X OPS 卡”上下文。未知上下文停止。效果归属当前 **OPS actor**，不跟着实体卡牌转交；头条先后比较仍使用印刷 OPS。

当前模板的报价按以下顺序进行，所有数值上限从 `ops_policy` 查询：

1. 汇总作用于 actor 的 Flat delta，再与基值相加得到 R。不能按效果注册顺序逐项截断。
2. 求整次行动历史满足的地区奖励 B。中国牌奖励只针对真实中国牌 OPS；越南奖励来自生效实例。东南亚属于亚洲。仅影响力／政变／调整可用地区奖励，太空和 OPS 门槛不能用。
3. `effective = max(minimum, min(ordinary_maximum, R) + B)`。其中普通上限不截掉地区奖励；下限在合并地区奖励后应用。

**PE-INTERPRETATION-01：** 此公式中的小值组合是按 §7.4“合并计算”推导的工程解释，未发现专门针对该组合的 FAQ，也不是用户专门确认的裁定。例如苏联 1 OPS、清洗 −1、越南东南亚 +1 得 1，不能先保底到 1 再额外加成到 2。实现前保留此解释标记，若新增权威资料相反，更新参数版本和验收预期。不同效果相抵属于本批已设计组合，同效果重复触发仍待核实。

官方 §7.4 的例子：苏联中国牌 4 + 亚洲 1 + 越南 1 − 清洗 1 = **5**。4 OPS 的美国同时受遏制和清洗则为 4；不能先截成 4 再减成 3。事件“视同打出 1 OPS 卡”在美国遏制生效后为 2，不能因为来自事件而漏算。

### 地区条件不能只看最后一个国家

每个候选操作先把目标追加到历史副本，再按完整历史重报价，检查 `spentAfter <= effective`，通过后才提交。空历史仅用于预览潜在奖励，不表示奖励已获得。

- 先在东南亚花 2，再花第 3 点也在东南亚，可以满足越南奖励。
- 若再尝试去东南亚以外，奖励失效且总支出超基础预算，则拒绝本次候选命令；此前已提交操作不回滚。
- 如果去外区后总支出仍合法，可执行，但此行动后续返回东南亚也不能恢复“全用于东南亚”。
- 影响力按实际 OPS 成本累计（敌控国家可能需 2 OPS），不是按标记个数。调整的失败投掷同样计入目标和支出。政变以其单一目标报价后结算。
- 奖励是可用上限，不强制使用奖励；是否可提前结束具体行动仍由该行动服务验证，不能从本服务新增通用跳过按钮。

上下文创建时冻结效果版本与激活序列。已完成行动不追溯重算，新子行动读取当时有效效果。若将来出现已花费的父 OPS 被中断、期间新增修正、再恢复父 OPS 的跨卡交互，必须另行核实；本批不默许重定价。

## 与其他模块接缝

- 太空的卡牌 OPS 资格接收 Flat 修正后的值；不接受越南或中国牌地区奖励。FAQ v5 p4 #6 明确允许中国牌用于太空；继续通过独立 ChinaState 转交，不进入普通弃牌堆。报价不替代中国牌的持有／正反面等使用资格验证。
- 普通政变强度与军事信用使用对应有效 OPS；免费政变的信用为零；战争事件按已验证事件固定值结算，不能把战争值自动修正。
- 事件直接影响力增减、地区计分、VP 和头条排序不调用此 OPS 修改路径。
- UI 只接收修正来源和当前状态投影。图标、写实／文明风格、动效均由表现层用 ID 查资源；不在规则参数中存材质或坐标。
- 实例存在不等于允许一切跨卡交互。新牌处理器必须声明支持的影响，不认识的相关干预返回 `RequiresRuling`；本批不解除经互会的短缺待裁定状态。
