# 全局平局状态与事件契约

description：查全局 Finished/Draw 的表示、已有历史重放与新行动守卫；不改变卡牌效果或局部骰子竞赛赢家。

Wargames 零分平局已获用户确认。八份完整状态契约原先只列 US、USSR 或空值，无法表示该全局结果：China 转交、Defectors、延迟 VP、晚期受限行动、晚期手牌、晚期影响力、晚期当回合限制、OPEC/北海石油。此次只向这些全局 winner 域加入 Draw，未改变玩家身份、控制方或卡牌效果。

逐项诊断发现：八份原 Schema 都拒绝 Draw，但八组参考模型的历史重放仍成功。它们核验历史收据，不根据后来 live 状态重新执行事件。因此本次修订的是状态表示，不能宣称修好了八个已复现的重放故障。

新增40项有限检查：16项契约检查覆盖 Finished/Draw 可表示及未知赢家拒绝，24项参考检查覆盖旧命令重放、新 Finished/Draw 行动拒绝、新活动状态含 Draw 的行动拒绝。核查只涉及各模型的主要事件入口，未穷举选择、到期及查询。活动状态含非空赢家由语义守卫拒绝；Schema 接受一个值并不等于该行动合法。

原有8组受影响用例共1943项重新运行；未变更部分2817项沿用此前4760项报告的历史证据，不说本批全部重跑。加上新40项后，已记录的独立设计案例总数为4800，本批实际执行1983项。中国牌、局部峰会/军备竞赛/奥运会赢家、地图、卡牌印刷与参数数值均未变。

这些模型使用合成终局状态，没有真实运行 Wargames→存档→其他事件的完整链路。该跨模块运行验收仍待实现。未来 C# 应区分 PlayerSide 与 GameResult；平局不是第三个玩家。现有 JSON 形状保持兼容，不借此提前创建源码。
