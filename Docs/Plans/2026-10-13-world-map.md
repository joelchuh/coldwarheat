# 世界地图占位视图实施计划

> 执行：按 executing-plans 在当前会话分步实现；用户已授权持续优化和占位地图，沿用已确认的 IMapView / MapLayout 边界。

目标：让同一局规则练习在世界轮廓上选国、查看影响力、缩放和平移。最终画风仍未确定。

架构：Core 地图保持国家、邻接和规则。Presentation 装配只读 Flat2D 布局与公共领域陆地轮廓，输出既有带上下文的 MapIntent。独立状态栏与事件确认按钮继续使用原控制器。

技术：Unity 6000.6.0f1、C# 9、已有 Newtonsoft.Json；不增加网络运行时、数据库或 GIS 依赖。

设计依据：Docs/Wiki/map-presentation.md、Docs/Design/implementation-architecture.proposal.md、Docs/Wiki/replaceable-map-view.md；本次只落实平面占位视图，不扩展规则裁决。

## 决定与边界

- 保留 Tiles / Table；增加 World 适配器。抽出可绘制视图基类，不让世界图继承列表行列排版。
- 布局覆盖 84 国家和 2 超级大国；坐标为左下原点、0–1 归一化等距经纬投影。标记是自制近似位置，合并国家按游戏 ID 标示，不作为疆界图。
- `Data/Presentation/world-layout.json` 沿用 layout v1，fixture、Flat2D、空 connection_routes、固定圆点拾取键。加载器明确仅支持此配置子集；拒绝 Mesh3D / 路线覆盖 / 未实现形状，不冒称完整 JSON Schema 执行器。
- `Data/Presentation/world-land.json` 保存 Natural Earth 公共领域陆地多边形，底图不含国界。几何不参与规则邻接。来源、下载哈希与转换方法单独记录。
- 两份数据先限制文本大小、深度、令牌、节点/顶点数，再验证重复字段、类型、有限数值、闭合轮廓和 ID 覆盖；加载失败阻止装配，不猜测默认坐标。
- 镜头仅有显示状态；缩放 1–12、拖拽、全图/所选国家定位，缩放保持光标下的地图位置（边界夹紧除外）。国家选择按屏幕热点最近距离，确定性 ID 打破并列；超级大国仅装饰。
- 换视图保留权威 GameState 和选择草稿；旧上下文、释放和帧保护继续生效。仅清晰可见、视口内的热点可拾取。
- 界面仍是规则诊断 Demo；没有完整出牌、回合调度和整局胜负。自动截图只验证实际渲染，不冒称鼠标验收。
