# 头条阶段接入现有试玩的实现边界

description: 将既有头条设计映射到实际CardZones、ActionPractice和Session；区分已存在服务与尚未实现的编排。2026-10-15。

状态：完整编排仍规划；独立[头条基础服务](../Wiki/headline-foundation.md)已有保留区和选择源码及托管补充验证，尚未挂接游戏。用户继续开发授权有效；Unity当前许可证不可用，先完成接线审计。现有Demo仍跳过头条，不能因为本设计存在就改变对外能力说明。

## 用户体验目标

一个窗口仍可切美国/苏联，各自在自己的手牌中提交头条。提交后锁定，普通视图只知道对手是否已提交；两方齐备才显示双方牌名和先后。测试观察独立只读，可查看双方。事件要求另一方选择时复用现有地图目标/分配交互，完成两张头条后进入苏联第一个普通行动。国家布局、译名和地图主题不承担阶段判定。

## 已核对规则与共享事实

依据[R2015 §4.5C](https://www.gmtgames.com/nnts/TS_Rules-2015.pdf)：秘密选牌后揭示，较大头条值先执行，同值美国先；计分牌参与头条且数值由共享参数指定；中国牌不参与；默认只执行事件，不凭印刷OPS另发预算；事件受益方和核战责任方分开。按事件逐张结算，不能预先批算后一张的结果。

`Data/Rulesets/deluxe-2015/turn-flow.json#/headline`已提供sort、tie_first_side、scoring_value。事件印刷数值读取CardDefinition.PrintedOps；当前OpsValuePurpose没有Headline，不向普通OPS报价硬塞新用途。SpaceAbilityRules.Query已返回OpponentRevealsHeadlineFirst，选择策略消费此现有资格；不要根据太空位置再复制一套阈值。

Defectors专门取消次序沿Docs/Wiki/defectors.md及其已核对参数/来源；不能仅按2 OPS排序。首次有限接线若没有对应处理器，选择前明确标未支持，不把它当空事件。嵌套借牌、揭手后OPS、特殊取消等按现有各模块契约另行接入。

## 分批落地顺序

1. 私有保留区、选择状态和排序纯服务。新服务先独立测试，不启用Demo按钮；读取共享参数，分普通同时秘密选择与太空先看后选策略。
2. 根完成路径区分头条/普通行动。先保证所有旧行动、对手事件顺序、终局及幂等回归不变，再接头条的七张计分牌与已注册十二个事件处理器。
3. Host、按身份过滤投影与UI。先显示选择/锁定/揭示/当前结算/等待Owner/完成这六种可理解状态；未知处理器在锁牌前拒绝。保留单人双边测试入口。
4. 开局和后续回合接入。增加独立构建，真实点击一组有等待选择的头条、一次计分头条和第二回合头条；旧播放器不覆盖。

不依赖最终美术，也不依赖数据库。头条选择、阶段、根责任、牌区、RNG及去重记录未来共同参与存档；本批不以设计文档声称已支持存档或联网。

## 关键失败边界

- 锁定后不可重选；错误不能返回对方CardId、数值或私有候选列表。
- 部署未完、正在普通行动、终局、未知事件、非法持有权、重复选择均在mutation前拒绝。
- 没有已支持的头条候选是试玩覆盖不足，显示明确边界，不能擅自弃牌、跳过头条或判负。
- 第一张事件结束且未终局后才重新检查第二张的条件；技术错误丢弃当前事务草稿，不假装事件正常无变化。
- 标星牌只按实际事件结果处理。被取消、前置不满足、成功无变化互不等价，复用已有专门规则。
- 太空先看后选资格影响揭示策略，不直接决定谁的事件先执行。

人工矩阵：切方时私有选择不泄露、提交按钮锁定、揭示区顺序正确、地图选择受益方提示、中文牌名与结算摘要可读、普通行动从苏联1开始。需真实窗口证据，自动测试不能替代。
