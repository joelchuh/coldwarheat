# 一次性事件与决策事务

description: 在同一GameState和LocalGameHost中接入五牌事件；用固定身份、版本、事件/决策ID与共同收据保护完整选择。

- 接续 `f116a2a` 的纯规划，未修改牌面事实或已确认裁定。
- Core增加事件Ready/AwaitingChoice/Resolved继续状态；开始只记请求，完整选择成功才提交全部变化和完成标记。普通OPS在事件完成前阻挡。
- Application增加类型化Begin/Resolve命令、只读公开事件和候选投影；玩家只交标识和目标，不能替换定义/受益方/数值。
- 原普通影响力与新事件共用同身份命令ID收据，保留成功与正常拒绝结果；同ID换类型也冲突。取消、并发、旧对局、溢出和视图隐私有实际回归。
