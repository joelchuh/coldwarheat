# 头条试玩人工验收

description: 只验收实际新播放器，单元测试不能替代本表；每次截图/点击以当前窗口为准。

目标播放器：Builds/HeadlinesPlaytest/ColdWarStruggleDemo.exe。旧LocalizedPlaytest保持原样。首次默认第15场景，测试观察关闭，既有真实发牌和示例部署不变。用户可主动勾选测试观察，以一个窗口测试美苏双方。

1. 检查标题、头条阶段、地图、右侧按钮、中文短名和默认未勾选的观察开关；中国牌不应可选。
2. 打开当前操作方手牌；未接头条效果的牌按钮禁用。选择合法牌，回地图确认锁定。
3. 切换另一方：只显示对方已锁定而不显示牌名；主动开启观察可见，关闭即隐藏；锁定方不能改选。
4. 另一方锁定；顺序/完成/取消根据实际队列显示。若出现国家选择，按事件Owner切身份，地图选国并完整确认。
5. 两张完成后检查苏联第1行动；从真实手牌完成一次行动；切视图和名称不改变局面。
6. 可用路线继续到回合末审核及下一回合，确认补牌后重新进入头条，不显示跳过头条。
7. 叛逃者取消和终局中断若本次初始牌没有覆盖，不编造人工通过，分别保留自动测试证据和待人工状态。
8. 窗口缩放、长牌名和小屏裁切单独记录，不把初始画面代表所有视图。

实际结果统一记入 headline-playtest.validation.json 的 ui 字段；停止/失败保留原因，不重复使用过期截图坐标。
